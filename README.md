# Talk2Tamil: Multilingual Translation Assistant

A Streamlit application that translates any text to Tamil or Simplified English with voice output and document generation.

## Features
- 📝 Multilingual input support
- 🇮🇳 Tamil translation with voice
- 🇬🇧 Simplified English output
- 🔊 Text-to-speech in both languages
- 📄 PDF/TXT document download
- 📁 File upload support (TXT, DOCX, PDF)
